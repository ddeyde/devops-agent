# DevOps-агент

ИИ-агент, который по одному запросу создаёт сервер приложения на Render, разворачивает
приложение из GitHub, проверяет его, находит и устраняет сбой, управляет сервисом.

## Быстрый старт

Нужны Claude Code, git, Python 3 и бесплатный аккаунт [Render](https://render.com).

1. Отправьте запрос из [PROMPT.md](PROMPT.md) первым сообщением в новый чат Claude Code.
2. Агент склонирует репозиторий и подготовит файл `.env`. Создайте ключ в Render
   (Account Settings, API Keys) и впишите его в этот файл. В чат ключ не вставляйте.
3. Напишите «готово». Остальное агент сделает сам и закончит отчётом.

Платить не нужно: агент создаёт только бесплатные сервисы, платный план инструмент отклоняет.

## Как понято задание

Формулировка: агент «создаёт сервер, разворачивает или управляет приложением», сдать
выгрузку агента или историю чата с переиспользуемым запросом и результатом.

Здесь есть и то, и другое. Агент закрывает все три части. Сервером считается web-сервис
Render: на этой же платформе размещена первая домашка, и она бесплатная.

## Состав

| Файл | Назначение |
|---|---|
| `PROMPT.md` | Переиспользуемый запрос с параметрами |
| `CLAUDE.md` | Роль агента, порядок работы, правила |
| `tools/render_api.py` | Инструмент агента для Render API, только стандартная библиотека Python |
| `tests/test_render_api.py` | Тесты инструмента на фейковом API |
| `results/clean-run.md` | История зачётного прогона |

Агент работает на Claude Code: модель выбирает шаги, инструмент их выполняет.

## Паттерны

| Паттерн | Реализация |
|---|---|
| План, действие, наблюдение | Следующий шаг только после чтения вывода предыдущего |
| Ограниченные инструменты | Агент работает с Render только через `render_api.py` |
| Защита на уровне инструмента | Платные планы, защищённые сервисы и удаление блокируются в коде |
| Человек в контуре | Подтверждение перед необратимыми и платными действиями |
| Самопроверка | Успех только после реального HTTP-ответа, а не статуса деплоя |
| Восстановление | Анализ логов, затем revert или rollback, лимит три попытки |
| Идемпотентность | Повторный запуск находит существующий сервис |

## Ограничения

- Виртуальной машины и SSH нет: Render это платформа, всё управление идёт через REST API.
- Render запускает одно приложение, `docker-compose` с Prometheus он не поднимает.
- Метрики Render на бесплатном тарифе скудные, счётчик запросов пуст. Запросы видны в логах.
- Учебный сбой требует прав на push в репозиторий приложения.
- Проверено на Windows, Claude Code и аккаунте Render с подключённым GitHub.

Тесты: `python -I tests/test_render_api.py`.
