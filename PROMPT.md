# Переиспользуемый запрос

Отправьте текст из блока первым сообщением в новый чат Claude Code. Папка может быть любой:
агент сам склонирует этот репозиторий. Параметры меняйте под своё приложение.

```text
Склонируй https://github.com/ddeyde/devops-agent и перейди в эту папку.
Если ты уже в ней, клонировать не нужно. Прочитай CLAUDE.md и выполни задачу по его правилам.

Режим: full
Репозиторий: https://github.com/ddeyde/devopsHW
Ветка: main
Имя сервиса: demo-app
Регион: frankfurt
Учебный сбой: нет
Разрешено удалить: нет

В конце дай отчёт в формате из CLAUDE.md.
```

При первом запуске агент подготовит файл `.env` и попросит вписать в него ключ Render.
Когда впишете, напишите в чат «готово».

## Параметры

| Параметр | Значения |
|---|---|
| Режим | `full`, `deploy`, `status`, `restart`, `rollback`, `destroy` |
| Репозиторий | URL публичного репозитория на GitHub |
| Ветка | Ветка для деплоя. Для учебного сбоя не основная |
| Имя сервиса | Уникальное имя в workspace Render |
| Регион | `frankfurt`, `oregon`, `ohio`, `singapore`, `virginia` |
| Учебный сбой | `да` или `нет`. Для `да` нужны права на push в репозиторий |
| Разрешено удалить | `нет` или имя сервиса |

## Другие примеры

Запрос зачётного прогона, с учебным сбоем:

```text
Ты DevOps-агент этого проекта. Выполни задачу по правилам из CLAUDE.md.

Режим: full
Репозиторий: https://github.com/ddeyde/devopsHW
Ветка: agent-demo
Имя сервиса: devopshw-agent
Регион: frankfurt
Учебный сбой: да
Разрешено удалить: нет

В конце дай отчёт в формате из CLAUDE.md.
```

Статический сайт, потом удаление:

```text
Склонируй https://github.com/ddeyde/devops-agent и перейди в эту папку.
Если ты уже в ней, клонировать не нужно. Прочитай CLAUDE.md и выполни задачу по его правилам.

Режим: full
Репозиторий: https://github.com/ddeyde/fenechki
Ветка: main
Имя сервиса: fenechki-agent
Регион: frankfurt
Учебный сбой: нет
Разрешено удалить: fenechki-agent

После проверки выполни режим destroy для этого сервиса.
В конце дай отчёт в формате из CLAUDE.md.
```

Проверка состояния:

```text
Склонируй https://github.com/ddeyde/devops-agent и перейди в эту папку.
Если ты уже в ней, клонировать не нужно. Прочитай CLAUDE.md и выполни задачу по его правилам.

Режим: status
Имя сервиса: demo-app
```
